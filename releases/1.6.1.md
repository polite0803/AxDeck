This release adds a page that gathers the updates available for every app installed on this PC, so they can be upgraded one by one instead of opening each app to look for its own update check.

Added
- Software updates: a new page that lists each installed app with a newer version, its current and available version, and where the update came from. A WinGet item upgrades silently in the background and a new check follows; an item that only offers a download page opens it.
- Three sources: `winget upgrade` for the main list, a built-in table of vendor and GitHub version endpoints for common apps WinGet does not recognise, and Windows' uninstall information to find what is installed.
- Checks run about 90 seconds after AxDeck starts and every six hours, back off 15 minutes, an hour and then four after a failure, and keep their result on this PC, so the last list still shows after a restart. The first check takes 1–2 minutes and runs in the background.
- Settings › Software updates turns the automatic check off or runs one at once; the page's size sits with the other pages under Settings › Expanded view.

这个版本新增一页，集中列出整台机器上已安装应用的可用更新，不必挨个打开应用、逐个点它自己的「检查更新」。

新增
- 软件更新：新增一页，列出每个有新版的应用、它的当前与可用版本，以及更新的来源。来源是 WinGet 的项在后台静默升级，完成后自动重新检查；只能手动下载的项会打开对应的下载页。
- 三层数据源：`winget upgrade` 给出主干列表；内置映射表向 GitHub Releases 与厂商接口查询 WinGet 认不出的常见应用（VS Code、Firefox、GitHub CLI、DBeaver、Obsidian）；Windows 的卸载信息用来找出这台机器上装了什么。
- 启动约 90 秒后检查一次，之后每 6 小时一次；失败按 15 分钟、1 小时、4 小时重试。结果保存在本机，重启后仍能看到上次的列表。首次检查约需 1～2 分钟，全程在后台。
- 「设置 › 软件更新」可以关闭自动检查，也可以立即检查一次；这一页的尺寸和其他页面一起在「设置 › 展开外观」里调整。
