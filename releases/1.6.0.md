This release connects AxDeck to the work already happening on this PC. Register the projects you choose, restore the tools and files a task needs, start a project-aware focus session, and see which watched AI tools are writing local session records. The new work page brings those records together without scanning project folders or reading conversations.

Added
- Development work: a new page that gathers registered projects, the focus countdown, today's completed sessions, AI work activity, recent text and named file groups.
- Projects: register a folder in Settings › Projects and work, then open it or restore it. Restore can bring forward or start a chosen launcher and prepare a default file group for the window you were using. AxDeck does not discover projects from disks, windows, processes or folder times.
- Project commands: Open, Restore and Focus on project are available in the command palette. `axdeck://project/<project id>`, `axdeck://restore-project/<project id>`, `axdeck://focus-project/<project id>`, `--project <project id>`, `--restore-project <project id>` and `--focus-project <project id>` cover shortcuts and scripts.
- Project-aware focus: a focus session can carry a project, a label and the AI work sources to watch. Completed or abandoned sessions keep a bounded local history, and the work page summarizes today's focus count and target minutes by project.
- AI work status: choose Claude Code, Codex, DSH, Kimi or Pi independently of the quota columns. The AI usage page shows whether each watched tool has local records, when the newest was written, and how many records are currently being written. Only file metadata is read.
- File groups: build named, ordered groups of paths in Settings › Projects and work, assign one as a project's default, or paste it from the command palette. Paths are stored; files are not copied.
- Session energy: the system power tooltip can show energy accumulated while the monitor is reading, together with the time actually covered by valid consecutive samples.
- Runtime diagnostics: the Services page now reports AxDeck's own CPU, working set, private memory, handles and threads, plus the availability of CPU, GPU, storage, temperature, power, battery and frame-rate readings. Actions open the owning settings page, offer frame-rate authorization when it is missing, or resume an automatically stopped reading.

Changed
- The AI work indicator is now a page-level status strip with record counts and the latest write time, instead of a working dot limited to tools that already have a quota column.
- Recent text and file groups can be pasted from the command palette, alongside project and focus commands.
- Copy diagnostics now includes the runtime capability report. It keeps host names, SSH hosts, ports, model paths, session contents and credentials out of the copied text.
- Project-linked service sites are explicit choices from `services.json`. The work page can copy a site's SSH, cloudflared or open command, but it does not start the command or probe the site.

Fixed
- A future timestamp in a local record is treated as "Now" rather than producing a negative relative time.

<!-- lang: zh-CN -->
这个版本让 AxDeck 接着本机正在进行的工作走：由你登记项目，把一项任务需要的程序和文件组恢复出来，从项目开始一次带上下文的专注，并看到正在写本机会话记录的 AI 工具。新的开发工作页把这些本机记录集中起来，但不扫描项目目录，也不读取对话内容。

新增
- 开发工作：新增一页，集中显示登记的项目、专注倒计时、今天已结束的专注、AI 工作活动、最近文本和命名文件组。
- 项目：在「设置 › 项目与工作」里登记目录后，可以从面板打开或恢复。恢复时可以把你指定的启动程序切到前台或启动，并把默认文件组准备到你打开面板前使用的窗口。AxDeck 不根据磁盘、窗口、进程或文件夹时间猜测项目。
- 项目命令：命令面板提供「打开项目」「恢复工作」「开始项目专注」。快捷方式和脚本可以使用 `axdeck://project/<项目ID>`、`axdeck://restore-project/<项目ID>`、`axdeck://focus-project/<项目ID>`，以及 `--project <项目ID>`、`--restore-project <项目ID>` 和 `--focus-project <项目ID>`。
- 项目专注：一次专注可以带上项目、名称和要观察的 AI 工作来源。完成或中途放弃的会话会在本机留下一段有上限的历史；开发工作页按项目汇总今天的专注次数与目标分钟数。
- AI 工作状态：可以独立于配额列选择 Claude Code、Codex、DSH、Kimi 或 Pi。AI 用量页会显示每个观察对象是否有本地记录、最近一次写入时间，以及当前有几个记录正在写入。这里只读文件元数据。
- 文件组：在「设置 › 项目与工作」里建立有名称、有顺序的文件组，可以指定为项目的默认文件组，也可以从命令面板直接粘贴。保存的是路径，不复制文件。
- 本次能耗：系统功耗的悬停提示可以显示监控读取期间累计的能量，并给出真正由连续有效采样覆盖的时长。
- 运行诊断：服务页会报告 AxDeck 自身的 CPU、工作集、私有内存、句柄和线程数，以及 CPU、GPU、存储、温度、功耗、电池和帧率读数是否可用。对应项目可以直接打开设置页；缺帧率授权时会进入现有授权流程，自动停用的读数也会提供重新开启入口。

改动
- AI 工作状态从只跟随配额列的小圆点，改为页面级状态条，并补上记录数与最近写入时间；没有配额列的工具也可以单独观察。
- 命令面板除项目和专注命令外，也可以粘贴最近的文本与文件组。
- 「复制诊断」现在包含运行能力报告，同时仍不包含主机名、SSH Host、端口、模型路径、会话内容、凭据或设置值。
- 项目关联站点只来自你手动选择的 `services.json` 条目。工作页可以复制站点对应的 SSH、cloudflared 或打开命令，但不会启动命令，也不会探测站点。

修正
- 本地记录的时间戳落在未来时，相对时间会显示为「刚刚」，不再出现负数时间。
