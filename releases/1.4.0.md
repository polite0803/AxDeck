This release turns the panel from something you read into something you can work from: quotas now show where they are heading, the music page can move the sound to another device, the clipboard can be read and turned into a QR code, and a focus timer, a command palette and `axdeck://` links let you drive the panel without hunting for a button.

Added
- AI usage: a curve behind each quota bar draws the day's readings, one every ten minutes, kept for 30 days and recorded even while the panel is collapsed. A tool that is writing its session records gets a coloured dot beside its title; only the file's modification time is read.
- Hovering a quota estimates when the recent pace reaches that row's warning line. With too few readings, or a share that is not rising, no estimate is given instead of a guess.
- Each app row can set its own warning and critical levels in Settings › Quotas and usage; leaving them empty keeps 70% and 90%. The quota ring, the bars and the notices all follow that row's levels.
- Today's traffic: disk read and write, and network down and up, accumulated in the background. The counters are remembered across a restart and reset at local midnight. It is off by default, in Settings › Display and readings › When expanded.
- Music: a translation line under the current lyric, a size smaller, from NetEase Cloud Music and QQ Music. Apple Music's TTML translations are not parsed. It is off by default, in Settings › Style › When expanded.
- Music: an output-device button lists this PC's playback devices and marks the current one, so the sound can be moved without opening Windows' own flyout.
- Clipboard: "Read the picture…" reads the text in a copied picture with Windows' own recogniser and any QR code with a decoder on this PC. Neither leaves the machine; a copied line of text can be turned into a QR code.
- Shelf: "Copy to desktop" and "Copy to folder…", and the choice to remove a record together with the original file.
- Settings can be exported to one `.json` file and imported on another PC (Settings › General › Back up and move). Keys are left out of the file, and so are the display, graphics card and device choices that belong to this machine.
- Services: BGE-M3 can start with Windows from its own startup entry, so the server is up without AxDeck having to run first, and its log can be read inside the panel.
- Focus timer: 15, 25, 45 or 60 minutes, with pause, resume and reset. It keeps running while the panel is collapsed and carries on after a restart; time spent asleep is not counted. The countdown can stand in the notch or the capsule, and a Windows notification marks the end. It is also in the tray menu.
- Command palette: the toolbar's command button, or its shortcut, opens a box that jumps to any page or runs an action — switch the collapsed style, refresh quotas now, open settings, hide the panel, toggle click-through, start a focus timer — from a few characters in either language, with the arrow keys, Enter and Esc.
- `axdeck://` links (`axdeck://page/music`, `axdeck://focus/25`, `axdeck://settings`) and a command line (`AxDeck.exe --page music`, `--focus 25`, `--search lyrics`, `--refresh`). With AxDeck already running, the new process hands the command to it and exits instead of opening a second panel.

Docs: README and the `docs/{en-US,zh-CN}` pages cover the new behaviour, and `privacy.md` lists the files these features keep on this PC.

<!-- lang: zh-CN -->
这个版本让面板从「只能看」变成「能直接用」：配额能看出走向，音乐页可以把声音切到别的设备，剪贴板里的图能读出内容、文字能生成二维码，专注计时、命令面板和 `axdeck://` 链接则让你不必到处找按钮。

新增
- AI 用量：每条配额条后面画一条当日的走势线，读数每 10 分钟最多记一条、保留 30 天，面板收起时也照常记录。某个工具正在写自己的会话记录时，标题旁会显示一个该应用颜色的小圆点；这里只读文件的修改时间。
- 鼠标停在配额上时，会按最近读数的速度估算大约什么时候到达这一行的告警线。读数不够、或者份额没有在上升时不估算，面板不猜。
- 每个应用行可以在「设置 › 配额与统计」里单独设置预警与告警比例，留空时仍为 70% 与 90%。配额环、进度条与提醒都按这一行自己的比例计算。
- 今日流量：后台累计磁盘读写与网络收发，重启后续算，跨本地零点归零。默认关闭，在「设置 › 显示与读数 › 展开时」开启。
- 音乐：在当前歌词下面加一行译文，字号小一号，来自网易云音乐与 QQ 音乐（Apple Music 的 TTML 译文暂不解析）。默认关闭，在「设置 › 样式 › 展开时」开启。
- 音乐：输出设备按钮列出本机的播放设备并标出当前设备，不必再打开 Windows 自己的面板就能切换。
- 剪贴板：「读取图片内容…」用 Windows 自带的识别组件读出图片里的文字，用本机的解码器读出二维码，两者都不联网；反过来，复制的一段文字也可以生成二维码。
- 文件中转：「复制到桌面」「复制到文件夹…」，以及在移除记录时连原文件一起删除。
- 设置可以导出成一个 `.json` 文件，带到另一台电脑导入（设置 › 常规 › 备份与迁移）。密钥不写进文件，与这台电脑绑定的显示器、显卡与设备选择也留在本机。
- 服务：BGE-M3 可以通过自己的开机自启项随 Windows 启动，不必先开 AxDeck，日志也能在面板里直接查看。
- 专注计时：15、25、45 或 60 分钟，可以暂停、继续与重置。面板收起后照常走，重启后接着走，睡眠时间不算。倒计时可以放进刘海或胶囊，结束时发一条 Windows 系统通知，托盘菜单里也能开始。
- 命令面板：工具栏的命令按钮或快捷键打开一个输入框，几个字就能跳到任意页面或执行动作——切换收起样式、立即刷新额度、打开设置、隐藏面板、切换鼠标穿透、开始专注计时；中英关键词都能匹配，方向键、Enter 与 Esc 可用。
- `axdeck://` 链接（`axdeck://page/music`、`axdeck://focus/25`、`axdeck://settings`）与命令行（`AxDeck.exe --page music`、`--focus 25`、`--search 音乐`、`--refresh`）。已有 AxDeck 在运行时，新进程把命令交给它后直接退出，不会开出第二个面板。
