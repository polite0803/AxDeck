This release rounds out the Desktop page: the keyboard now does what the desktop's keyboard does, files can be copied and pasted in and out, and a review of the page fixed the faults it had gathered — pages that stopped refreshing, icons that showed the wrong picture, entries that went missing, and restores that turned the desktop the wrong way.

Added
- The keyboard the desktop itself takes: the arrow keys move the focus (Shift extends the selection, Home and End jump to the edges), Enter opens, F2 renames in place — a box over the name with the main name selected, Enter confirms, Esc or clicking away gives up, and a name Windows refuses is reported instead of applied — Delete sends the selection to the recycle bin, Ctrl+A selects everything, Alt+Enter shows the properties (system entries' properties too), the menu key or Shift+F10 opens the system menu, F5 refreshes and Esc clears the selection.
- The clipboard, in Explorer's own format: Ctrl+C copies and Ctrl+X cuts the selection, Ctrl+V pastes what the clipboard holds onto the desktop — copied files are copied in, cut files are moved in and deletions land in the recycle bin. What is copied here pastes into File Explorer and other programs, and what Explorer has copied pastes in here.
- The page refreshes itself: while it shows, watchers on the two desktop folders redraw it shortly after files change, and the collapsed panel does no work at all.

Fixed
- After leaving the Desktop page once, it never refreshed again: the watcher bookkeeping treated the timer left over from the first watch as the sign that watching was under way, so the watchers were never rebuilt and file changes went unnoticed. The timer is cleared on leaving, and the events it receives — which arrive on background threads — are marshalled to the UI thread, where two events at once could orphan a timer or throw while it was being disposed.
- A file dragged out of the page and dropped back on it produced a "name (2)" copy. The guard that skips files already in the target folder only answered for moves; copying a file onto its own folder is skipped too now.
- The shared desktop (where installers put their shortcuts) was found by a GUID that does not exist in Windows, so the lookup always failed and fell back to another answer that worked; the right GUID is used now. Shortcuts the user removed from the desktop were drawn anyway, because the filter read a header bit that every shortcut carries; the dead filter is gone and the page draws what lies in the folders, as the desktop does.
- On machines that never touched the "show desktop icon" switches for This PC and Network, the page hid both entries: a missing registry value was answered with the entry's default instead of Windows' rule, which shows an icon Windows itself put there. Icons a file carries are also cached by their change time, so a file whose icon changed shows its new one without a restart, and the page sorts with Explorer's own comparison, so "file2" sits before "file10" exactly as on the desktop.
- Taking over the desktop could restore the wrong state on exit: the state before the takeover was read from the registry, which Explorer only writes when it toggles the icons itself. The state is now read from what the desktop really shows, with the registry as fallback; recovery also skips the toggle when Explorer already draws the icons, so a run that retakes the desktop right away does not flash it.
- Choosing properties, opening the system menu of a system entry, and a few quieter paths (a shell file operation's error and its Cancel, the page's own context menu being collapsed away with the panel) are checked now where they once were swallowed or half-handled.

本次发布补齐了「桌面」页的键盘操作与剪贴板，并把一轮代码审阅找出的缺陷一并修掉：不再刷新的页面、显示错误图标的项、凭空消失的条目，以及退出时把桌面还原错方向的问题。

新增
- 桌面本来的那套键盘：方向键移动焦点（Shift 连选，Home/End 跳到首尾），回车打开，F2 就地改名——名字上盖一个输入框、预选主名，回车确认，Esc 或点开别处放弃，Windows 不接受的名字会提示而不是执行——Delete 把选中项放进回收站，Ctrl+A 全选，Alt+Enter 查看属性（系统项的属性同样可以看），菜单键或 Shift+F10 弹出系统菜单，F5 刷新，Esc 清除选择。
- 剪贴板与资源管理器同一套格式：Ctrl+C 复制、Ctrl+X 剪切选中项，Ctrl+V 把剪贴板上的文件放到桌面上——复制来的复制过来，剪切的搬过来，删除进回收站。从这里复制的内容可以粘贴进资源管理器和其他程序，资源管理器复制的内容也可以粘贴到这里。
- 页面会自己刷新：显示期间，两个桌面文件夹上的观察器在文件变化后稍作停顿即重画；面板收起时一个字节也不花。

修正
- 离开一次「桌面」页之后，它就再也不刷新了：观察器的簿记把第一次观察留下的定时器当成了「正在观察」的标志，观察器从此不再重建，文件的变化全部错过。离开时定时器会清掉；它收到的事件本来从后台线程进来，现在封送回 UI 线程——两个事件同时到时，那里可能留下一个空跑的孤儿定时器，或在销定时器时抛出异常。
- 从页面里拖出去再拖回来的文件，会多出一份「名字 (2)」副本。「已在目标文件夹里的文件跳过」这道防备只对移动生效，现在复制同样跳过。
- 找公共桌面（安装程序放快捷方式的那个）用的 GUID 在 Windows 里并不存在，查询一直失败、靠另一个答案兜底，现在换成了对的。用户从桌面移除的快捷方式仍然被画出来，因为过滤器读的是每个快捷方式都带着的一个头部标志位；这个从不生效的过滤器删掉了，页面和桌面一样画文件夹里有什么。
- 在从没动过「显示桌面图标」开关的机器上，「此电脑」和「网络」两项被当成了藏着的：注册表里没有值时，代码用了条目的默认值，而 Windows 的规矩是无值即显示。文件图标同时改为按修改时间进缓存，文件换了图标不用重启就能显示新图；排序也换成了资源管理器自己的比较，「file2」排在「file10」前面，跟桌面一致。
- 接管桌面后退出时可能还原错状态：接管前的样子是从注册表读的，而 Explorer 只在自己切换图标时才写注册表。现在先问桌面实际画成什么样，注册表只作后备；恢复时 Explorer 已经画着图标就不再切换，刚启动就要再次接管的运行不会让桌面闪一下。
- 属性对话框、系统项的系统菜单，以及几处更安静的路径（shell 文件操作的报错与取消、页面自己的右键菜单被连着面板收掉）过去被吞掉或只处理了一半，现在都按实际结果处理。
