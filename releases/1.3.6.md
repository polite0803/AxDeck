This release adds Windows notifications for the notices the panel shows, and fixes two faults on the Desktop page that made some icons sit in the wrong place.

Added
- A quota rising into the warning (70%) or critical (90%) level can now also send a Windows notification, which lands in the notification centre, at the same moment as the notice in the collapsed panel. It is sent even while the panel is hidden or kept off a full-screen app. The text follows the in-panel notice, including whether it shows what is used or what is left, with the reset time.
- A device whose charge crosses into the getting-low or low level can send a Windows notification too, with the charge it has left. A charging device sends none. Each crossing notifies once, and a device that disconnects and comes back starts over.
- Both are off by default, in Settings › Quotas and usage › Notifications and Settings › Devices › Low-battery notices. Notifications are sent from the tray icon, which is switched on in General; with the tray icon off, they are not sent.

Fixed
- Two icons jumped to the end of the Desktop page, and dragging could not place them: the user desktop and the public desktop both held a shortcut of the same name, and an item matching more than one row of Explorer's icon list was given no position at all. The first matching row is taken now, which is the user desktop's copy — the one the page draws.
- The user folder had no position on the Desktop page and was pushed to the end: its position was matched against the Profile directory's name, while Explorer draws the account's display name, and the two differ whenever the account has been renamed. The name Explorer draws is asked for and matched too.

这个版本为面板里的提醒补上了 Windows 系统通知，并修好了桌面页上两个让图标位置不对的问题。

新增
- 某个工具的配额升到预警（70%）或告警（90%）时，除了收起的刘海或胶囊显示提醒，还可以同时发一条 Windows 系统通知，出现在通知中心；面板被隐藏或全屏免打扰时也会发送。通知内容与面板里的提醒一致，按“配额显示”中的设置显示已用或剩余比例，并附重置时间。
- 设备的电量降到预警或告警阈值以下时，也可以发一条 Windows 系统通知，写明还剩多少电；充电中的设备不发。每次跨越阈值只提醒一次，设备断开后重新连接，重新按此计算。
- 两项都默认关闭，分别在“设置 › 配额与统计 › 提示”和“设置 › 设备 › 低电量通知”中开启。通知从系统托盘图标发出，需要在“常规”中开启托盘图标；关闭托盘图标时不发送。

修复
- 桌面页上有两个图标跳到末尾、拖动也放不上去：用户桌面与公共桌面里有同名的快捷方式，而与资源管理器图标列表中多行匹配的项被当成没有位置。现在取第一条匹配的行，即用户桌面的那一份，也就是这一页画出来的那个图标。
- “用户文件夹”在桌面页上没有位置，被挤到末尾：它的位置按 Profile 目录名去匹配，而资源管理器画的是账户的显示名，账户改名后两者就不同了。现在同时按资源管理器画的名称匹配。
