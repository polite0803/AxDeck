This release finishes the Desktop page the previous one added: the tiled organizer windows it replaced are gone, and three faults on the page are fixed.

Changed
- The desktop organizer is one page now. The tiled box windows, the folders they held, and everything only they used are removed: eleven types, five of them windows, and the nine rules on the settings page that no page read any more. What the Desktop page does set stays — the icon size, the two gaps, how names are written, what happens to a file of the same name — and settings saved by an older version still read back: the icon size, the gaps and the name display the user already chose are kept, not reset to the default.

Fixed
- Clicking an icon on the Desktop page did nothing: no single click to select, no double click to open. Only the artwork itself took the press; the name below it, the padding around it and the space between cells let the click through to the window underneath, because a layered window passes a click through wherever it has drawn nothing.
- The Desktop page read only the current user's desktop, so the shortcuts installers put on the public desktop (C:\Users\Public\Desktop) — WeChat, Teams and other machine-wide installs — never appeared. Both folders are read now, the way Explorer reads them, and the user's own copy wins when a name is in both.
- Restoring the Desktop page's defaults left the page drawing the settings that had just been reset, and the next save wrote them back. Restoring reloads the page's data now, and puts back any desktop icon the discarded data still had recorded as hidden.

本次发布把上一版新增的「桌面」页做完：它取代的那套平铺分组窗口已经整套删除，页面上三处问题也已修好。

变化
- 桌面整理只剩一页。平铺的分组窗口、它们各自收着文件的文件夹，以及只有它们才用得上的东西全部删掉：11 个类型，其中 5 个是窗口；设置页里 9 条已经没有任何页面读取的规则也一并去掉。桌面页自己的设置照旧——图标大小、横竖两种间距、名字怎么写、遇到同名文件怎么办——老版本存下的设置照样读得回来，用户调过的图标大小、间距和名字写法不会被重置成默认值。
- 修正：在「桌面」页上点击图标没有反应，单击不选中、双击不打开。只有图标图案本身能接住点击，图案下面的名字、四周的留白和格子之间的空隙都让点击穿到了下层窗口——分层窗口在没有画过东西的地方会直接放行点击。
- 修正：「桌面」页只读了当前用户的桌面，安装程序放在公共桌面（`C:\Users\Public\Desktop`）上的快捷方式——微信、Teams 等整机安装的程序——一个都不显示。现在两个文件夹都读，读法与资源管理器一致，同名时以用户自己的那份为准。
- 修正：把「桌面页」的设置恢复默认后，这一页画的还是刚被重置掉的旧值，下一次保存又把旧值写了回去。现在恢复默认会重新加载这一页的数据，并把旧数据里还记着的、被藏起来的桌面图标先放回桌面。
