The Desktop page can now be tidied up by hand: drag an icon onto another and it takes that place. The order is the real position of the desktop icons, so the desktop and the page agree whichever one you arrange them on.

Added
- Dragging an icon onto another reorders the page. Drop it on the left half of the target to put it before, on the right half to put it after; a line marks where it will land, and the icons you drag follow the pointer. Selecting several first moves them as one group, keeping the order they had. Esc gives up the drag.
- The order is the desktop's own: positions are read from Explorer's icon list and written back to it through the same list, so the order shown on the page is the order the desktop keeps, and icons arranged in the real desktop show up in that order here.
- Only the order changes. Each icon takes a place another one of them held, so nothing is pushed off the list, and entries the page does not draw — such as the system entries hidden by their switches — keep the places they had.
- Dragging an icon out of the page still copies it to another program, as before; only a drop back on the page's own icons reorders.

「桌面」页现在可以手动整理了：把一个图标拖到另一个图标上，它就换到那个位置。这个顺序就是桌面图标的真实位置，所以在哪一边摆，另一边都跟着一致。

新增
- 把图标拖到另一个图标上就能排序。落在目标左半边插在它前面，右半边插在它后面；拖动时有一条竖线标出落点，被拖的图标跟着指针走。先选中多项再拖会整组一起移动，组内保持原来的先后。Esc 放弃这次拖动。
- 顺序就是桌面自己的顺序：位置从资源管理器的图标列表里读出，也通过同一个列表写回去，所以页面上看到的顺序就是桌面保存的顺序，在真实桌面上摆好的图标在这里也按那个顺序显示。
- 只改顺序，不改谁在桌面上。每个图标拿的是同批图标里另一个空出来的位置，所以不会有图标被甩出列表；这一页没画的项——比如被开关藏起来的系统项——原来的位置也不动。
- 从这一页把图标拖出去仍然是复制给别的程序，与原来一致；只有落回本页的图标上才是排序。
