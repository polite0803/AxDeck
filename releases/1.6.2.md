This release fixes the Update button on the software updates page, which looked as if it did nothing.

Fixed
- The Update button now upgrades the package it names. `winget upgrade` prints five columns (Name, Id, Version, Available, Source) and AxDeck read only four of them, so every row shifted one place: the available version became the source name and the package id became a version number. The upgrade then asked winget for a version number and matched no package.
- The list a previous version left on this PC is discarded once, so the page shows a correct list after the next check instead of the old shifted rows.
- A failed upgrade now says why in the status line, in winget's own words, instead of only turning the button into Retry. An item that has left the list, and a download page that will not open, say so too.

这个版本修好「软件更新」页上的「更新」按钮：此前点下去看起来没有任何反应。

修复
- 「更新」现在真的会升级它标出的那个包。`winget upgrade` 的输出是五列（名称、ID、版本、可用、源），AxDeck 只读前四列，于是每一行都错位一格：可用版本变成了源名，包 ID 变成了版本号。升级时拿版本号去查，winget 找不到任何包。
- 旧版本留在本机的那份列表会被丢弃一次：下一轮检查之后这一页显示的是正确的列表，而不是旧的错位行。
- 升级失败现在会在状态行给出 winget 的原话，而不只是把按钮变成「重试」。这一行已经不在列表里、或下载页打不开，也会说明一句。
