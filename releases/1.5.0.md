This release gives the panel a more deliberate visual system: quieter graphite surfaces, clearer hierarchy, and more consistent controls across the main panel and settings.

Changed
- Reworked the panel's surface layers, borders, corners, shadows, and toolbar geometry so the interface reads as a compact instrument rather than a collection of floating cards.
- Added structured theme surface roles for raised, toolbar, inset, active, quota, and input areas. Built-in dark, light, high-contrast, and custom themes now resolve these roles consistently, including contrast handling.
- Unified buttons, icon controls, menus, tooltips, text fields, sliders, switches, and focus states around shared radii, spacing, dynamic theme colors, and clearer hover and pressed feedback.
- Tightened toolbar icons and controls to a consistent 16 px glyph size and 28 by 24 DIP hit area, and reduced reliance on decorative accent fills.
- Improved labels and accessibility names for several controls, and reduced popup shadow weight for a cleaner, faster-feeling layered window.

这个版本重新整理了面板的视觉系统：更克制的石墨层级、更清楚的界面秩序，以及主面板和设置页里更一致的控件表现。

改动
- 重做面板的表面层级、描边、圆角、阴影和工具栏几何，让界面更像一块紧凑的仪器面板，而不是一组漂浮的卡片。
- 增加 raised、toolbar、inset、active、quota、input 等结构化主题表面角色。内置深色、浅色、高对比度主题与自定义主题会一致解析这些角色，并纳入对比度计算。
- 统一按钮、图标控件、菜单、工具提示、文本框、滑杆、开关和焦点状态的圆角、间距、动态主题颜色，以及悬停和按下反馈。
- 工具栏图标统一为 16 px 字形，点击区域统一为 28 × 24 DIP，并减少装饰性强调色填充。
- 补充部分控件的标签与无障碍名称，减轻弹出层阴影，让分层窗口更干净、响应感更直接。
