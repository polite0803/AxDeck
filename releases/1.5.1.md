This release gives the expanded panel and the settings window one visual system: layered surfaces instead of floating cards, a hierarchy that says which line leads, and controls that share one language. It includes the visual refresh written up for 1.5.0, which was not published on its own.

Changed
- Reworked the panel's surface layers, borders, corners, shadows and toolbar geometry so the interface reads as a compact instrument rather than a collection of floating cards.
- Added structured theme surface roles for raised, toolbar, inset, active and quota areas. They follow a theme's own background and foreground, so a light theme built on a dark one no longer shows dark cards, and the night look of a theme gets its own values.
- Unified buttons, icon controls, menus, tooltips, text fields, sliders, switches and focus states around shared radii, spacing, theme colors and clearer hover and pressed feedback. Toolbar controls are a consistent 16 px glyph in a 28 by 24 DIP hit area.
- The settings window no longer sets every row in semibold: weight belongs to the page title and the group headings, which are now a step above the rows in size, and the rows separate by hairlines. A segmented control's chosen option is filled with the accent, as a switch's on state is, instead of a grey block needing an outline.
- Column separators, the rule above the totals and the services page's status bar fade out at both ends, so the panel reads as one page rather than as boxes.
- The clock is centred in the room the page switch and the right-hand buttons leave it, and is hidden when that room is too small, so it no longer meets the buttons on a narrow page.
- On the system monitor page, the tick over a bar is a short faint mark in its middle rather than a line cutting the bar in two, and two process rows that trade places turn over in place instead of sliding through each other.
- An empty quota column is set on the column's own text grid, with a quiet text action to sync, rather than as a centred block with an outlined button.

Fixed
- The theme contrast check measured text against surfaces no text is drawn on, which moved every color for a background it never appears on.
- The clipboard page's search box placed itself using the clock's old position at the middle of the whole panel.

这个版本让展开面板与设置窗口共用一套视觉系统：有层次的表面，不再是一组漂浮的卡片；有先后的文字层级；彼此一致的控件。其中包含 1.5.0 的视觉刷新，那部分此前没有单独发布。

改动
- 重做面板的表面层级、描边、圆角、阴影和工具栏几何，让界面更像一块紧凑的仪器面板，而不是一组漂浮的卡片。
- 增加 raised、toolbar、inset、active、quota 等结构化主题表面角色。它们随主题自己的底色与前景生成，所以以深色主题为基础搭出来的浅色主题不会顶着深色卡片，带夜间外观的主题也会有自己的取值。
- 统一按钮、图标控件、菜单、工具提示、文本框、滑杆、开关和焦点状态的圆角、间距、主题颜色，以及悬停和按下反馈。工具栏控件统一为 16 px 字形、28 × 24 DIP 的点击区域。
- 设置窗口不再把每一行都设成半粗体：字重留给页面标题与分组标题，分组标题比行大一级，行与行之间以细线分隔。分段控件的选中项改为强调色填充，与开关的「开」一致，不再是一块需要描边才看得出的灰底。
- 列与列之间的分隔线、总计上方的细线和「服务/工具」页的状态条改为两端渐隐，面板读起来是一整页，而不是一个个方框。
- 时钟改在页面切换器与右侧按钮让出的空间里居中；空间不够时自动隐藏，窄页面上不会再和按钮撞在一起。
- 系统监控页上，压在柱子上的读数改为柱心一道短而淡的痕迹，不再是一条把柱子切断的线；两行进程交换位置时原地翻，不再互相穿过。
- 空配额列改为按列自己的文字栅格排版，并配一个安静的文字动作来同步，不再是居中的整块加一颗描边按钮。

修正
- 主题对比度检查把文字拿去和「不会有文字画上去的表面」比较，导致颜色为一个它从不出现在上面的背景而调整。
- 剪贴板页的搜索框仍按「时钟在整个面板正中」的旧位置计算，可能与时钟重叠。
