AxDeck keeps everything the panel did before, and adds a desktop of its own: the real desktop is empty while AxDeck runs, and the desktop's contents live on the new Desktop page.

New
- New "Desktop" page: the desktop's files, folders, shortcuts and system entries (This PC, Recycle Bin and the rest, the ones the user has not turned off) draw as icons in the deck, ordered the way Explorer orders them. A shortcut the user has taken off the desktop stays off: its "show on the desktop" flag is read from the .lnk file itself. Double-click opens an item, the right-click menu is Explorer's own, Delete sends an item to the Recycle Bin, Ctrl and Shift and Ctrl+A select, F5 refreshes, and files drag in from Explorer and out to other programs. The blank space has its own menu: refresh, open the desktop folder, organizer settings.
- New desktop takeover: while AxDeck runs, Windows' desktop icons are hidden, so the desktop is clean and the desktop's contents are only visible on the Desktop page. What the icons were set to before AxDeck started is remembered and put back when it exits; a run that ends without exiting (a crash, ending the process) puts them back on the next start. The takeover is a switch in Settings > Expanded view, and it takes effect without a restart.
- The desktop organizer is now a page in the settings window (Settings > Desktop organizer) instead of a page in the deck. Its box windows stay where they were; the tray menu and the Desktop page's menu both lead to its settings.
- New in the organizer: a box folds down to its title bar when the pointer leaves it and unfolds when it comes back; the gap between icons has its own two sliders; a box's title is edited where it is written, with a double click.

面板此前的功能全部保留，并新增了它自己的桌面：AxDeck 运行期间真实桌面是空的，桌面的内容搬进了新的「桌面」页。

新功能
- 新增「桌面」页：桌面的文件、文件夹、快捷方式和系统项（此电脑、回收站等用户没有关掉的那些）以图标画在展开面板里，顺序跟资源管理器一致。用户从桌面拿掉的快捷方式不会回来：它「显示在桌面上」的标志直接从 .lnk 文件头读出来。双击打开，右键菜单是资源管理器自己的，Delete 把一项送进回收站，Ctrl、Shift、Ctrl+A 多选，F5 刷新，文件可以从资源管理器拖进来、也可以拖出去给别的程序。空白处有自己的菜单：刷新、打开桌面文件夹、整理设置。
- 新增桌面接管：AxDeck 运行期间 Windows 的桌面图标是藏起来的，桌面保持清洁，桌面的内容只在「桌面」页里看得见。AxDeck 启动前图标是什么状态会被记住，退出时照原样放回去；一次没有走到退出就结束的运行（崩溃、结束进程）会在下次启动时把图标放回去。接管是「设置 > 展开外观」里的一个开关，改动即时生效，不必重启。
- 「桌面整理」不再是展开面板的一页，改为设置窗口里的一个页面（设置 > 桌面整理）。分组的窗口照旧；托盘菜单和「桌面」页的菜单都指向它的设置。
- 整理器的新功能：鼠标离开分组时它收成一条标题栏，鼠标回来再展开；图标之间的空隙有了自己的两个滑块；分组的标题就地改名，双击标题即可。
