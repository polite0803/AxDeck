# 桌面页

展开面板的「桌面」页把 Windows 桌面搬进面板：桌面文件夹（含公共桌面）里的文件、文件夹和快捷方式，加上「此电脑」「回收站」等系统项，都按桌面的样子画在这一页上。这一页的大小在「设置 › 展开外观」中（宽度、高度）；页面的开关与顺序在「设置 › 展开视图」中。

## 接管桌面

- 「设置 › 展开外观 › 运行时接管桌面」开启时（默认开启），AxDeck 运行期间 Windows 自己画的桌面图标是隐藏的，桌面上的内容只在 AxDeck 的这一页里看得见；AxDeck 退出或关闭该开关时，图标按原来的样子放回。
- 隐藏与放回走的是 Windows 自己的「查看 › 显示桌面图标」开关；AxDeck 退出时按接管前的状态恢复，异常退出后下一次启动也会把图标找回来。
- 关闭接管后，真实桌面照常由 Windows 画，这一页只是同一份内容在面板里的镜像，两边互不影响。

## 页面上的内容

- 显示两个桌面文件夹合起来的一份：你自己的桌面（`Desktop`）和所有账户共用的公共桌面（安装程序常把快捷方式放在那里）。带「隐藏」属性的文件（如 `desktop.ini`）不显示，与桌面的习惯一致。
- 公共桌面的一半只读：那里的项可以看、可以打开，但改名、删除等写入操作只对你自己桌面上的项有效（公共桌面通常需要管理员权限才能写）。
- 系统项（此电脑、回收站、网络、控制面板、用户文件夹）按 Windows 的设置显示：在桌面上隐藏了哪一项，这一页就不画哪一项；也可以在「设置 › 桌面页」里逐项开关。
- 桌面文件夹有变化时（文件增删、改名），这一页自动刷新；面板收起时不做任何工作，展开时会先重画一遍。

## 选择与打开

- **单击**选中一项；**Ctrl + 单击**加选或取消；**Shift + 单击**从焦点项连选到所点的一项。
- **双击**打开，与桌面的习惯相同：文件用它自己的程序打开，文件夹进入资源管理器，快捷方式启动目标，系统项交给系统处理。
- 选中多项后回车，会逐项打开。

## 拖入与拖出

- **拖入**：把文件或文件夹从资源管理器拖到这一页，松开即复制到桌面（原处保留）。落下的位置由一条竖线指示；文件较多时复制在后台进行，完成后自动刷新。
- 拖入时遇到同名文件，按「设置 › 桌面页 › 遇到同名文件时」处理：自动改名、跳过或替换旧的。
- **拖出**：把这一页的项拖进资源管理器或其他程序，得到的是副本（文件仍在桌面上）。系统项没有文件，拖不出去。

## 剪贴板

- **Ctrl + C** 复制选中的项，**Ctrl + X** 剪切，**Ctrl + V** 把剪贴板上的文件粘贴到桌面：复制来的复制过来，剪切的搬过来（走系统 shell，资源管理器当场可见，删除进回收站）。
- 剪贴板格式与资源管理器相同（CF_HDROP + Preferred DropEffect），在这里复制的内容可以粘贴到资源管理器和其他程序；在资源管理器复制的文件也可以粘贴到这一页。
- 自己桌面上的项再粘贴回桌面不会产生重复：已在目标位置的项自动跳过。

## 键盘操作

焦点在这一页上时，与桌面相同的键都可以用：

| 键 | 作用 |
| --- | --- |
| 方向键 | 移动焦点；按住 Shift 连选 |
| Home / End | 跳到第一项 / 最后一项；按住 Shift 连选 |
| Enter | 打开选中项 |
| F2 | 重命名选中的项 |
| Delete | 把选中项放进回收站 |
| Ctrl + C / X / V | 复制 / 剪切 / 粘贴 |
| Ctrl + A | 全选 |
| Alt + Enter | 打开选中项的属性 |
| 菜单键或 Shift + F10 | 弹出选中项的系统右键菜单 |
| F5 | 刷新 |
| Esc | 取消选择 |

重命名与桌面相同：输入框预选主名（快捷方式不带 `.lnk`），回车确认、Esc 或移开焦点放弃。Windows 不接受的名字（保留设备名、非法字符等）会提示而不执行。

## 右键菜单

- **在项上右键**：弹出 Explorer 自己的那份菜单，压缩、发送到、用其他程序打开等都在里面；对系统项同样有效。菜单里做的改动（改名、删除）会立即反映到这一页。
- **在空白处右键**：这一页自己的菜单——刷新、打开桌面文件夹、桌面页设置。

## 属性

选中一项按 **Alt + Enter**，打开与资源管理器「属性」相同的对话框；系统项（此电脑、回收站）的属性同样可以查看。

## 设置

桌面页相关的设置有三处：

- **设置 › 展开外观**：页面宽度与高度、「运行时接管桌面」开关。
- **设置 › 桌面页 › 规则**：遇到同名文件时（自动改名 / 跳过 / 替换旧的）、图标下的名字（显示全部 / 快捷方式不写 `.lnk` / 不写任何扩展名）。
- **设置 › 桌面页 › 外观与开关**：图标大小、名字字号、图标横向与纵向间距、圆角，是否显示名字、快捷方式是否带小箭头，以及各系统项桌面图标的显示开关。
